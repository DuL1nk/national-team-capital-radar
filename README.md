# 国家队资金雷达

[打开固定网站](https://dul1nk.github.io/national-team-capital-radar/) · [云端运行记录](https://github.com/DuL1nk/national-team-capital-radar/actions/workflows/daily-data.yml)

无模型数据版由 GitHub Actions 每天北京时间09:15启动，并设错峰恢复；当天资金页已发布后，按小时轻量核查分位官方月报及机构公告正文。有可靠新披露即通过同一串行流程更新，不重抓ETF长历史、不增加第二发布者。取数、历史核验、单文件日报/研究图生成、持久化数据提交、Pages发布和匿名SHA-256验收均在云端运行，不依赖个人电脑开机。GitHub定时可能延迟，不是准点完成承诺。

- 资金统计：最新已审计纯宽基池与独立央企/政策池，官方份额×同日NAV，保留逐产品长历史、已核拆合校正和覆盖缺口。
- 图表：长中短期、五年区间、三层资金筛选、累计资金/六指数/两种沪深300占比分位叠加。
- 机构：官方PDF按明确主体、数据日、单位和严格规则确认新数量；实际增减持与可见持仓净变化分开，未知格式待复核。不按标题推断数量，不把ETF申赎归到国家队账户。“今日核查”不等于每家机构均有日频披露。
- 新闻分析未启用；规则摘要不是投资建议。月报分母可以滞后，缺失不补零或前填，指标不是账户仓位或胜率。
- 新事件、产品映射/转型、历史修订或关键源不完整时停止发布，保留旧站点并在Actions中记录失败。

源码与公共基线在[automation](automation/README.md)，网页只部署静态白名单，不部署源码、状态数据库或原始抓取文件。这里没有个人账号持仓、浏览器状态或私密凭证。原历史页面保留；达到容量门禁后需另行决定归档方式，不静默删除。

人工重跑：Actions → Daily data refresh → Run workflow；默认不发布预览，确认发布时选择`publish=true`。这不是自动交易系统。
